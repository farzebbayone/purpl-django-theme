Toast Notifications

Use for non-blocking feedback after user actions — save confirmations, error alerts, background task completions.

Rendered with Purpl's .bds-toast, which has three variants — success, warning, error. Its unmodified base is info-accented, so ThemeToast.info() and .ai() render as that neutral base. JS API: ThemeToast.success("message")
