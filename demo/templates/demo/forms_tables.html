Standard Editor

Full toolbar with headings, formatting, lists, links, code blocks, and images.

Welcome to Purpl

This is a rich text editor powered by Quill, styled to match the Purpl theme. It supports:

  • Bold, italic, and underline formatting
  • Ordered and unordered lists
  • Multiple heading levels
  • Code blocks and inline code
  • Links and blockquotes
The editor automatically adapts to light and dark modes, matching your theme preference.

Try editing this content or switching to dark mode to see the themed styling.

Read-only

Display rich content without editing. No toolbar shown.

This editor is in read-only mode. The toolbar is hidden and the content cannot be modified. Useful for displaying user-generated rich text.

Pre-rendered HTML can also be shown without initializing Quill at all.

Integration
CDN Setup
<!-- In your template's extra_head block -->
<link href="https://cdn.jsdelivr.net/npm/quill@2/dist/quill.snow.css"
      rel="stylesheet">

<!-- In your template's extra_js block -->
<script src="https://cdn.jsdelivr.net/npm/quill@2/dist/quill.js">
</script>

<script>
const quill = new Quill('#editor', {
  theme: 'snow',
  placeholder: 'Write something...',
  modules: {
    toolbar: [
      [{ header: [2, 3, false] }],
      ['bold', 'italic', 'underline'],
      ['link', 'code-block'],
      [{ list: 'ordered' }, { list: 'bullet' }],
      ['clean']
    ]
  }
});
</script>
Django Form Sync
<!-- Hidden textarea for form submission -->
<form method="post">
  {% csrf_token %}
  <div id="editor"></div>
  <input type="hidden" name="content"
         id="content-field">
</form>

<script>
const quill = new Quill('#editor', {
  theme: 'snow'
});

// Sync editor content to hidden field
const form = document.querySelector('form');
form.addEventListener('submit', function() {
  document.getElementById('content-field')
    .value = quill.root.innerHTML;
});
</script>
